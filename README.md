# ESSM IT Operations Portfolio

This repository is a professional IT operations portfolio built to demonstrate hands-on experience with systems administration, infrastructure troubleshooting, Linux, Windows Server, networking, Docker, automation, documentation, and homelab operations.

## Purpose

The goal of this portfolio is to show practical, real-world IT skills through documented projects, scripts, diagrams, troubleshooting notes, and repeatable playbooks.

## Core Areas

- Linux administration
- Windows Server administration
- Active Directory and DNS
- Networking and troubleshooting
- Docker and self-hosted services
- Storage and file sharing
- Automation and scripting
- Documentation and operational playbooks

## Repository Structure

| Folder | Purpose |
|---|---|
| docs | General documentation and architecture notes |
| diagrams | Network and infrastructure diagrams |
| scripts | Bash, PowerShell, and automation scripts |
| playbooks | Repeatable IT procedures |
| troubleshooting | Problem-solving notes and case studies |
| windows-admin | Windows Server and workstation administration |
| linux-admin | Linux administration and command references |
| networking | Network design, DNS, DHCP, VLANs, and troubleshooting |
| docker | Docker service notes and deployment examples |
| resume-projects | Projects suitable for resume and interview discussion |
