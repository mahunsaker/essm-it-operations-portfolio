# Troubleshooting Case Studies

These case studies show how technical problems in the ESSM HomeLab were investigated, resolved, validated, and documented.

## Cases

- [Linux SSH connection refused](linux-ssh-connection-refused.md)
- [Mattermost mobile connectivity](mattermost-mobile-connectivity.md)
- [Cross-platform SSH administration from WSL](wsl-cross-platform-ssh.md)

Each case follows a support-oriented process: document the symptom, verify connectivity, isolate the affected layer, determine the cause, implement a controlled correction, and validate the result.
